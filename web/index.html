Add group

        
A group is a folder of targets under one site name (e.g. Google → ICMP, DNS). It needs at least one target; the group-level Vantages/Alerts below are inherited by every target under it. Add more later with the folder's +.

        
        
        
        
        
        
        
        

        
        
        

          
          
        

      

    


    

      

        
Import YAML

        
Paste a YAML (or JSON) config. Its targets: branches are merged into the database config; globals (database/probes/alerts) are ignored. An existing target with different settings is a conflict (nothing is imported).
