The smoke graph, rebuilt on canvas

Reproducing SmokePing's signature latency-distribution chart from a modern client-side renderer. Each vertical slice shows the spread of N pings that round — the dark cloud is jitter, the colored line is the median tinted by packet loss. Rendered here from the same sorted per-round sample arrays the Go collector already returns from /api/series.

Jitter min → median → max spread
Loss

What to check: the dense dark core = tightly-clustered pings (low jitter); a tall fuzzy cloud = high variance; the median line changes color where pings are lost. This is the exact algorithm from the code map (§05): nested percentile bands darkening toward the median, an 8-bucket green→red loss ramp on the median, and unison Y-scaling. In the production build this same renderer reads live data and is fully theme-aware — the graphs adapt to dark mode instead of being baked light like the current Perl/RRDtool SVGs.
